Pagtanggap sa mga tuntunin

Sa paggamit ng ColorPick, sumasang-ayon kang gamitin ang site nang responsable at ayon sa mga naaangkop na batas. Kung hindi ka sang-ayon, huwag gamitin ang serbisyo.

Serbisyo

Nagbibigay ang ColorPick ng browser tools para sa pagtukoy ng kulay, pag-explore ng palette, color suggestions, harmonies, at HEX, RGB at HSL information.

Impormasyon sa kulay

Ang color values at generated palettes ay mga praktikal na reference para sa design. Ikaw ang dapat mag-check ng contrast, brand standards, print requirements at device differences.

Katanggap-tanggap na paggamit

Huwag gamitin ang site para sa ilegal na gawain, hindi awtorisadong access, malware, pang-aabuso ng automated requests o sadyang pag-abala sa serbisyo. Gumamit lamang ng mga larawang may karapatan kang gamitin.

Intelektuwal na ari-arian

Maaaring protektado ng intellectual-property laws ang ColorPick name, website design, original text, code at iba pang original materials. Huwag kopyahin o i-republish ang buong site bilang iyo nang walang pahintulot.

Iyong nilalaman

Ikaw ang responsable sa pagkakaroon ng karapatang gamitin ang larawang ina-upload o pinoproseso. Ang kasalukuyang workflow ay nagpoproseso ng larawan sa browser at hindi nangangailangan ng upload sa ColorPick server.

Pagkakaroon ng serbisyo

Sinisikap naming panatilihing available ang ColorPick, ngunit maaaring magkaroon ng pansamantalang interruption dahil sa maintenance, browser changes, hosting o network issues.

Hindi propesyonal na payo

Ang ColorPick ay general-purpose design at educational utility, hindi propesyonal na payo. Suriin ang mahahalagang resulta gamit ang angkop na tools at standards.

Limitasyon ng pananagutan

Sa lawak na pinapayagan ng batas, hindi mananagot ang ColorPick at operators nito para sa indirect o consequential losses mula sa paggamit ng site, color information, downtime o data loss.

Mga pagbabago

Maaaring baguhin ang mga tuntunin habang umuunlad ang site. Ang patuloy na paggamit pagkatapos ng pagbabago ay nangangahulugang pagtanggap sa lawak na pinapayagan ng batas.

Pakikipag-ugnayan

Para sa mga tanong tungkol sa tuntunin, gamitin ang Contact page sa colorpikertool.com.
