ColorPick guide

為什麼要使用圖片取色工具？

ColorPick適合處理一個常見的設計需求：從圖片、螢幕截圖、照片、插畫或設計參考中找出可使用的數位色彩。與其憑眼睛猜測顏色，不如上傳圖片、選取需要的區域，再將HEX、RGB或HSL數值複製到設計或程式碼中。

ColorPick 如何運作？

選擇圖片後，取色工具會在瀏覽器中讀取圖片，讓你直接查看並選取顏色。將游標移到圖片上可預覽顏色，點擊即可選取。選取的顏色會以多種格式顯示，也可以加入My Palette，從同一張圖片持續整理需要的色彩。

了解 HEX、RGB 與 HSL

HEX使用十六進位通道值表示顏色，CSS中非常常見。RGB表示紅、綠、藍三個通道的數值。HSL則以色相、飽和度與明度描述顏色，方便理解和調整。三種格式都是同一數位顏色的不同表示方式，互相轉換並不會自動產生新的顏色。

從圖片建立色盤的實用流程

先從圖片中選取重要顏色，例如背景、主要強調色、文字、插畫細節或產品元素。將重要顏色保存到My Palette，再使用Color Code、Color Suggestions或Color Wheel探索色階與搭配色。發佈設計前，請在最終使用情境中確認顏色，因為對比度與周圍顏色會影響實際視覺效果。

更準確取色的小技巧

可以的話，請使用原始圖片或最高品質版本。壓縮過的截圖可能因壓縮與影像效果而改變像素值。遇到漸層、陰影、照片或紋理時，建議取樣多個位置，而不是只依賴單一像素。ColorPick提供取樣到的數位數值，但最終設計仍應在實際螢幕與介面中確認。

How do I pick a color from an image?

Upload an image, move the pointer over it, and click the area you want. ColorPick shows the selected color and its HEX, RGB and HSL values.

Does ColorPick upload my image to a server?

The image picker reads the selected image in your browser so you can sample colors locally. The contact form is a separate feature that can send a message when you submit it.

What color formats does ColorPick show?

The picker provides HEX, RGB and HSL values so you can use the same color in web design, UI, graphics and other digital projects.
