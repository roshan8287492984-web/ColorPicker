How to use a color palette

A palette becomes easier to apply when each color has a clear job. Start with the visual role you need, then adjust the number of colors instead of trying to use every swatch at once.

Build a simple UI color system

Use one color for the main action or brand accent, one or two supporting colors, and separate surface, background and text colors. Keep repeated roles consistent so buttons, links and states feel related.

BackgroundLarge areas and page framing
SurfaceCards, panels and controls
TextPrimary and secondary reading content
PrimaryMain action or brand color
AccentSmall highlights and supporting states

Choose by project

For a website or app, look for palettes with enough separation between surfaces and text. For branding, prioritize a small set that can be repeated across logos and marketing. For illustration, a larger palette can be useful when you need more expressive variation.

From image to palette

Working with HEX codes

Each swatch exposes its HEX value and can be copied individually; the palette action can copy the full set. Treat the HEX values as reusable building blocks for CSS, design tokens, mockups and handoff notes.

A quick accessibility check

A palette can look harmonious and still produce weak text contrast. Before shipping a UI, check the contrast of actual text/background pairs and make sure interactive states remain distinguishable.

What makes a palette useful?

A useful palette gives you related colors with distinct roles, so you can build a consistent interface or visual system without choosing every color from scratch.

How should I start using a palette in a website?

Assign roles first: background, surface, text, primary action and accent. Then test those roles on real components such as buttons, cards, links and form fields.
