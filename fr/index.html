Réponses rapides

Des réponses pratiques aux questions courantes sur cet outil ColorPick.

Comment choisir une couleur dans une image ?

Téléversez une image, déplacez le pointeur dessus et cliquez sur la zone souhaitée. ColorPick affiche les valeurs HEX, RGB et HSL.

ColorPick envoie-t-il mon image sur un serveur ?

Le sélecteur lit l’image dans votre navigateur pour prélever les couleurs localement. Le formulaire de contact est une fonction distincte qui peut envoyer un message.

Quels formats de couleur sont affichés ?

Le sélecteur fournit les valeurs HEX, RGB et HSL pour le web, les interfaces, les graphiques et les projets numériques.
