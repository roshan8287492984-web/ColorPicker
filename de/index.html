Wie wähle ich eine Farbe aus einem Bild?

Lade ein Bild hoch, bewege den Zeiger darüber und klicke auf die gewünschte Stelle. ColorPick zeigt HEX-, RGB- und HSL-Werte.

Wird mein Bild auf einen Server hochgeladen?

Der Farbwähler liest das ausgewählte Bild im Browser, damit Farben lokal ausgewählt werden können. Das Kontaktformular ist davon getrennt und kann beim Absenden eine Nachricht senden.

Welche Farbformate zeigt ColorPick?

Der Farbwähler liefert HEX-, RGB- und HSL-Werte für Webdesign, UI, Grafiken und andere digitale Projekte.
